# Code of Conduct

Be direct, be kind, argue about the evidence and not the person.

Specifically: technical disagreement is welcome and should be settled by a test case, a
measurement, or a reproducible command. Harassment, personal attacks, and discrimination of any
kind are not welcome and will get you removed from the project's spaces.

Reports go to the maintainer through
[GitHub private vulnerability reporting](https://github.com/bram-wq/agent-guardrails/security/advisories/new)
(it is private and reaches only the maintainer) or by opening an issue if the matter is public.
Reports are handled confidentially.
